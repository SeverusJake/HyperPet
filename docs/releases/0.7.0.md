# HyperPet 0.7.0

## New features

- Choose a pet display in Settings → General → Pet monitor. Automatic uses the
  current/last monitor. A disconnected preferred display falls back to the
  nearest available display and remains saved for reconnection.
- Running, Desktop roaming and Come honor the selected display. Automatic Come
  targets the monitor under the cursor.
- Notifications now wait in a FIFO queue instead of replacing the current
  bubble. Use Next/Dismiss to advance. Up to 100 pending alerts are retained;
  overflow drops the oldest pending alert.
- Notification history is available from the bubble, pet menu and tray menu.
  Read or replay the newest 50 accepted notifications and clear the history.
  History is session-only and is never saved to disk. Replay does not duplicate
  history entries.
- Pause, quiet hours and exit clear pending alerts. Disabling full notification
  content also redacts current, queued and historical message text.

## Fixes and maintenance

- Replaced ImageSharp with SkiaSharp 4.155.0 (MIT). No Six Labors key is needed.
  PNG, WebP, transparency, frame crops and the bundled pet are covered by tests.
  License and third-party notices are included in the distribution.
- Uninstall removes the Windows startup Run entry independently of user-data
  cleanup.
- Tuck Away cannot be interrupted by new/expiring alerts. Competing timers and
  interaction are stopped, and a bounded fallback handles animations that
  cannot complete.
- Normalized and clipped roaming ledges to the selected display's work area.
- Fixed bubble controls being covered by the pet image and Automatic Come
  selecting an adjacent monitor near a shared display edge.

- SHA256SUMS.txt: SHA-256 checksums of the five distribution/update files.

## Validation and limitations

- 174 Release tests pass (61 Core, 113 App).
- NuGet audit including transitive packages reports no known vulnerabilities.
- Monitor disconnection/reconnection and DPI coordinates are covered with
  synthetic displays. Multiple physical displays with different DPI have not
  been tested end to end.
- Existing in-app notification limitations remain: Windows notification access
  currently gates startup of the in-app watcher, and reused same-position popup
  windows may retain cached text. These are separate from the new queue/history.
