# HyperPet 0.7.1

## Notification improvements

- Notifications automatically choose free space above, right, left, or below
  the pet and stay inside the selected monitor's work area. The notification
  follows movement, pet-size changes and display/work-area updates without
  changing the pet window's size.
- Long titles and messages can be read completely by scrolling. Hover over a
  notification to pause its expiry timer; leaving it resumes the timer.
- Click the notification to advance to the next queued message. Clicking the
  last message dismisses it. Removed the Next/Dismiss text buttons.
- History is now a small icon in the notification's upper-right corner. The
  icon and scrollbar do not consume notifications. History remains session-only.
- Notification clicks now advance/dismiss rather than opening the source app;
  removed the obsolete click-to-open setting from the settings window.
- Notifications appear without stealing focus and hide on pause, Tuck Away or
  exit. Fixed fractional-pixel sizing at 125% DPI causing an unnecessary
  scrollbar on short messages.

## Downloads

- **HyperPet-v0.7.1-win-Setup.exe**: installer with updater support.
- **HyperPet-v0.7.1-win-Portable.zip**: extract and launch HyperPet.exe.
- Full/delta nupkg and releases.win.json: updater files.
- SHA256SUMS.txt: SHA-256 checksums of the five distribution/update files.

Both Setup and Portable filenames now include the release version.

## Validation and limitations

- 198 Release tests pass (61 Core, 137 App).
- NuGet audit including transitive packages reports no known vulnerabilities.
- Actual WPF rendering checked with short/long messages and at 125% DPI.
- Physical multi-monitor transitions with different DPI remain unvalidated.
- Existing in-app notification limitations remain: Windows notification access
  gates watcher startup, and reused same-position popups may retain cached text.
