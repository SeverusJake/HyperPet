# HyperPet 0.6.1

## Changes

- Start with Windows is enabled by default for new settings. Existing saved
  startup choices are preserved, and registration is applied at launch.
- Added Remember pet position on launch, enabled by default, with Apply, Save,
  and Default support. Disable it to open at the default position.
- Restore placement before starting pet movement onto the nearest available
  monitor, and use that monitor's horizontal bounds in Running mode.
- Removed the unused drag-state field (CS0414).
- Updated the transitive System.Drawing.Common dependency to 8.0.34.
- Packaging now stops if Velopack fails.

## Downloads

- HyperPet-win-Setup.exe: installer, recommended for automatic updates.
- HyperPet-v0.6.1-win-Portable.zip: extract and run HyperPet.exe.
- Full/delta nupkg and releases.win.json: updater assets.

## Validation and known limitations

112 tests pass in Release configuration. Login-startup, uninstall, and mixed-DPI
monitor behavior have not been verified end to end on a real installation.

SixLabors.ImageSharp 3.1.12 still has known NuGet security advisories, including
[a TIFF decoding vulnerability](https://github.com/advisories/GHSA-v76p-62qx-wwq2).
The patched 3.2.0 package requires a license key not configured in this repository.
This release retains the existing image dependency; only import pet assets you
trust. This is a known dependency issue, not a claim that all advisory code paths
are exercised by HyperPet.

Existing issues found during review include stale text caching for reused in-app
popup windows, in-app monitoring being gated by Windows notification permission,
startup registration not being removed on uninstall, and mixed-DPI roaming.
See [the review](https://github.com/SeverusJake/HyperPet/blob/v0.6.1/docs/reviews/2026-11-11-release-review.md)
for the full prioritized list.
